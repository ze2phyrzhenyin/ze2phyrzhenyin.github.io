    On screen

    Build
    Paper, dust and vignette are computed as transparent images. PowerPoint has no blend modes: a texture is baked into the picture or laid over it as a semi-transparent image. A photographic old book or poster needs a real photo or a generated plate.

  2. 0:05Kinetic type

    On screen
    One shot per slide, and the whole slide runs on one timeline. Three words, each moving the way it reads: heavy, scatter, aligned.
    Build
    Every effect starts With Previous and is placed by its delay. For letter-by-letter motion, turn the text into shapes first with Merge Shapes > Fragment. FUJI’s 19 slides hold 2,063 animation behaviours.

  3. 0:15Frame by frame

    On screen
    A hand-drawn swirl moves, and every frame is a separate drawing.
    Build
    A set of shapes, each visible for 0.05 s: every 0.05 s one appears and one disappears.

    FromFUJI, PowerPoint Motion Graphics 2020

  4. 0:21Pattern and exception

    On screen
    The same grid appears twice, and the second time its state has changed. Pitch’s slide 2 pairs four old tools with two new ones each; on slide 3 the grid turns grey and gains a coloured column with PowerPoint and Pitch.
    Build
    Morph joins the two slides. It pairs objects by name: the same name on both slides, starting with two exclamation marks, same object type, used once per slide.

    FromPitch Series B deck

  5. 0:28Hard cut

    On screen
    The click is the cut. SMOKE spreads a 15-word sentence over 15 clicks: one to three words on black, then a photo on white, alternating.
    Build
    No transitions. The text anchor stays 5% from the left and 28% from the top, and each click finishes a clause. For a self-running sequence, set the slide to advance after 0 seconds.

    FromSMOKE - The Convenient Truth

  6. 0:40Fixed layout

    On screen
    The layout holds and only the art changes. Monument Valley talk, slides 14 to 18: art on the left at 42% of the width, bleeding top and bottom; headline, hairline and one sentence on the right; the headline keeps its coordinates on all five.
    Build
    Lock the layout and change one element from slide to slide. Text sits on white, never on the art. In the reel, Morph links the three slides and the isometric shapes are drawn in code.

    FromMonument Valley GDC talk

  7. 0:51The crop

    On screen
    The subject runs off the slide. HyperloopTT shows one object from three positions: outside, cutaway, inside.
    Build
    Let the subject touch the slide edge and be cut by it; something centred in a box looks pasted on. Crop a picture into a window, move the window on the next slide, and Morph gives a push-in or parallax.

Checklist

Content

  • Write the story before opening a slide. One thing per slide, readable in 3 seconds.
  • Make the title a conclusion; the rest of the slide is its evidence.
  • A sentence can run over several slides, one clause per click.
  • Build the deck you present and the deck you send as two files.

Layout

  • Lock the layout and change one element across consecutive slides.
  • One typeface, five or six sizes set far apart.
  • Let the subject touch the slide edge and be cut by it. Something centred in a box looks pasted on.
  • Keep type and pictures apart. To put type on a picture, give it a solid panel.
  • One spot of accent colour per slide.

Animation, by hand in PowerPoint

  • Start everything With Previous and time it with delays. That is the timeline.
  • Set slides to advance after 0 seconds and use the slide change as a cut.
  • Morph pairs objects by name: the same name on both slides, starting with two exclamation marks, same type, once per slide.
  • Crop a picture into a window; with the window in a different place on the next slide, Morph produces a push-in or parallax.
  • For letter-by-letter motion, convert the text to shapes first: Merge Shapes > Fragment.
  • Frame by frame: a set of shapes, each shown for 0.05 s.
  • Loops: Smooth Start and Smooth End at 0, Repeat set to Until End of Slide.

What breaks off your machine

  • Morph becomes a fade in older PowerPoint, Google Slides and LibreOffice. Charts take no part in Morph.
  • Morph will not reshape a form with more than one hole, such as B or 8 once converted to shapes.
  • PowerPoint for the web ignores embedded fonts. Variable fonts show their default weight only.
  • Google Slides drops delays, motion paths and most effects.
  • Keynote opens the .pptx with the layout intact. Animation written as keyframes is reduced to appear and disappear; the same motion written with PowerPoint’s own effects (motion paths, Grow/Shrink, Spin) plays (tested in this project).
  • Video: MP4 with H.264 and AAC.

Open-source tools

  • ppt-master (MIT): SVG to native shapes, with PowerPoint’s 203 preset animations and 48 transitions.
  • OfficeCLI (Apache-2.0): reads and writes Office files from the command line, with animations, a Morph name check and a built-in renderer.
  • Slidev --format pptx-editable and dom-to-pptx: web page to editable .pptx.
  • HyperFrames (Apache-2.0) and Remotion (free for individuals and companies of up to 3 people): web page rendered frame by frame to MP4.

Repositories checked on 26 November 2026.

AI deck generators

Copilot, Gamma, Canva, Kimi and similar tools produce clean business slides. No independent source was found showing agency-level work from any of them. The ones with stronger visuals lose animation, or turn slides into images, when exporting to .pptx.

What code makes possible

Easing curves
PowerPoint’s interface offers Smooth Start, Smooth End and Bounce End. The file format accepts keyframes on a property animation: PowerPoint’s own Center Revolve preset uses 21. Sample any curve into keyframes and it can be written in. Not possible by hand; possible in code.
Type as outlines
HarfBuzz shapes the text and Skia removes overlaps, so each glyph and each of its parts is a shape. It looks the same on every machine and can move by glyph or by stroke. The text can no longer be edited.
Computed textures
Paper, dust and vignette are computed as transparent images, with no stock library. PowerPoint has no blend modes: bake the texture into the picture or lay it on top as a semi-transparent image.
One script
One Python script describes the scenes and the timeline, and writes a native .pptx, a scrubbable browser preview and an MP4.

Verified

  • All three language versions pass Office file-structure validation and ppt-master’s animation validator in its default mode.
  • LibreOffice, WPS and Keynote all open the files, and the static frames match the preview.
  • Keynote opens both .pptx files with the correct layout. It plays the motion of the stock-effects file, with one artefact: a shape that enters from an offset shows for one frame at its rest position. From the keyframed file it keeps only appear and disappear.
  • Animation attribute names and formula syntax match the XML of PowerPoint’s own presets.

Not verified

  • Playback of either .pptx in PowerPoint desktop. Neither the Mac nor the server used for this has PowerPoint installed.
  • Playback of either .pptx in WPS slideshow mode. Only checked that WPS opens the file and the frames are right.
  • The browser preview is this project’s own renderer; its Morph interpolation will not match PowerPoint’s exactly.
